# Instruction entry point

Resolve from this common root. A `TEMPLATE.json` installation-package without a registered canonical worktree is
payload: inspection/maintenance is allowed; installation and project execution require a separate request/setup.

For installed work, require exactly one real worktree at `agents-base/` or `.worktrees/agents-base/`, on branch
`agents-base` in this repository; set absolute `AGENT_BASE` and read its `AGENTS.md`. Report missing/ambiguous setup.
Keep task worktrees below this root. Configure explicit loading if the engine misses ancestor instructions.
