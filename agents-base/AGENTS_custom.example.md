# Local preferences example

Copy to ignored AGENTS_custom.md in canonical AGENT_BASE. Never commit it or include secrets/project settings.
Preferences cannot override shared invariants or explicit user instructions. A changed file is relevant context
and must be detected through its handoff hash; no private content is copied into task state.

- Conversation language: Follow the user.
- Detail and updates: Concise, evidence-based, focused on decisions and blockers.
- Providers/models: Follow explicit user preferences and live engine capabilities; none required by this template.
